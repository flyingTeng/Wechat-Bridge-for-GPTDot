## 再次验证

先安装依赖，并把 `.openai/hosting.example.json` 复制为本地 `.openai/hosting.json`，然后运行：

```sh
npm run check
```

该命令依次测试、运行时测试、类型检查、lint 和构建，不部署、不绑定微信、不创建调度任务。出现任何失败时应诊断具体原因，不跳过检查后宣称部署成功。
